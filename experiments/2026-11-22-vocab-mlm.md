## Hypothesis

The frozen Serengeti-vocabulary run skipped the masked-LM step FVT prescribes. With the new embeddings trained, a vocabulary that splits words less should match or beat the original vocabulary given the same training.

## Setup

- **Base model:** Davlan/afro-xlmr-large-76L
- **Models:** (a) Serengeti vocabulary moved in by FVT, then masked-LM on the input embeddings only; (b) control: AfroXLMR with the same masked-LM pass
- **Masked-LM pass:** WURA (kin, swa, zul) and MADLAD-400 (lug), 20,000 blocks of 128 tokens per language, 3,000 steps of 32 blocks (micro-batches of 8, gradients accumulated), lr 5e-4, tied output layer
- **PEFT method:** tuned LoRA from the sweep (NER r=32 qv, POS r=8 qv), up to 20 epochs, early stopping after 3
- **Languages:** kin, lug, swa, zul; 3 seeds
- **Hardware:** A100 40 GB, bf16 (both models)

## Results

Full tables: `results/mlm_summary.md`.

| Comparison | Metric | Serengeti + MLM minus AfroXLMR + MLM |

| lug→kin | NER | −4.7 [−6.2, −3.3] |
| 12 transfer cells | NER / POS | +1.4 / −0.4 |
| held-out MLM loss after | per token | Serengeti 3.2 to 3.6, AfroXLMR 1.2 to 1.4 |

## Observations

- Option B does not help in-language even with the masked-LM step; lower in every language and task.
- The NER isiZulu transfer gain replicates the frozen run against a matched control; POS does not show it.
- The new embeddings look undertrained after 3,000 embedding-only steps.
- The masked-LM pass barely moved plain AfroXLMR's loss.
