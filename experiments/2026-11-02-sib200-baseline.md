## Hypothesis

Reference topic-classification scores for every later method; check that LoRA matches full fine-tuning and see whether Bantu languages transfer better to each other.

## Setup

- **Base model:** Davlan/afro-xlmr-large-76L
- **PEFT method:** full fine-tuning vs LoRA r=8 (query, value)
- **Languages:** amh, hau, kin, lug, swa, zul
- **Dataset(s):** SIB-200 (701 / 99 / 204)
- **Task(s):** topic classification, in-language and zero-shot 6x6
- **Hyperparameters:** 3 seeds
- **Hardware / runtime / memory:** L4; LoRA 0.33% trainable, 4.4 GB vs 11.3 GB, about 43 s vs 140 s per run

## Results

| Language | Metric | Full | LoRA |
|---|---|---|---|
| 5 languages | accuracy | 84 to 89% | similar |
| lug | accuracy | about 70% | about 70% |
| pooled LoRA minus full | points | | +0.7, 95% CI [−1.1, +2.4] (sentences and seeds) |

## Observations

- LoRA matches full fine-tuning.
- Transfer is 92 to 102% of in-language; the target explains about 95% of the variation; no Bantu advantage.
- Luganda is weak only here (see the Luganda diagnostic).
